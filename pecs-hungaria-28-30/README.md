# Pécs, Hungária utca 28–30., 1. emelet

Ez a mappa egy pécsi belvárosi ingatlan teljes adatlap-csomagját tartalmazza a megadott paraméterek alapján.

## Tartalom

| Fájl | Célja |
|---|---|
| [`index.html`](./index.html) | Modern, reszponzív, egyoldalas, **nyomtatásbarát** ingatlan adatlap. Külső függőség nélkül megnyitható bármely böngészőben vagy PDF-be menthető. |
| [`adatlap.md`](./adatlap.md) | Strukturált Markdown adatlap (táblázatos, másolható bármilyen dokumentumba). |
| [`befektetesi-elemzes.md`](./befektetesi-elemzes.md) | Hasznosítási forgatókönyvek, CAPEX-szcenáriók, pénzügyi modellezési képletek, kockázatok és ajánlott due diligence lépések. |

## Gyors összefoglaló

- **Cím:** Pécs, Hungária utca 28–30., 1. emelet
- **Alapterület:** 114 m² lakás + 100 m² beépíthető tetőtér (~214 m² potenciál)
- **Sajátosságok:** saját privát lépcsőház, zárt udvari parkoló, A energetikai osztály, saját gázkazán, déli tájolás
- **Környezet:** Belváros-közeli prémium lokáció, 2023-ban megújult utca (Zöld kapu), PTE közvetlen közelében
- **Közös költség:** ~20 000 Ft/hó

## Használat

Az `index.html` közvetlenül megnyitható böngészőben:

```bash
xdg-open index.html   # Linux
open index.html       # macOS
start index.html      # Windows
```

PDF-be mentéshez használd a böngésző **Print → Save as PDF** funkcióját — az oldal nyomtatásra optimalizált stílussal rendelkezik.
